# Image Carousel / Slider

A responsive image slider built using HTML, CSS, and JavaScript. It allows users to browse images manually or enjoy automatic slide rotation with smooth transitions.

## ✨ Features

- **Image Slides:** Displays at least five images.
- **Next and Previous Controls:** Navigate between slides easily.
- **Automatic Rotation:** Slides change automatically at regular intervals.
- **Pause on Hover:** Pauses automatic rotation when hovering over the slider.
- **Slide Indicators:** Shows the current slide and allows direct navigation.
- **Smooth Transitions:** Creates a seamless image browsing experience.
- **Responsive Design:** Adapts to different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📁 Project Structure

```text
image-carousel-slider/

```

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Add your images to the images folder and update their paths if needed.
4. Open `index.html` in your browser.
5. Use the navigation arrows and slide indicators to browse images.
6. Hover over the slider to test the pause-on-hover feature.

## 📚 Key Learnings

- DOM manipulation and array indexing.
- JavaScript timers using `setInterval()`.
- Event handling for navigation controls.
- CSS transitions and responsive layouts.
- Managing automatic rotation and manual navigation.
